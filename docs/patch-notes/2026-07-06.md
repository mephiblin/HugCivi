## Civitai Rendered Webm Image Pages

Time: 00:19 KST
Commit: `pending`
Status: verified

### Summary

- Civitai image-page downloads now handle rendered-page video entries such as `https://civitai.red/images/97376108`, where the public API returns no items and the rendered page exposes a `VideoObject` plus a webm asset ID.
