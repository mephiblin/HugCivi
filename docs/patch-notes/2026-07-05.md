# Text And Markdown Document Cards

Commits: `7e7d417`
Status: verified

## Summary

- `.txt`, `.md`, and `.markdown` files are now treated as readable document media.
- Document-only folders can appear as library cards, and mixed archives such as ASMR.one works can show text files in the media strip next to audio/images.
- `/api/media/text` reads document previews with a 512KB cap and returns JSON with `truncated`, `encoding`, and size metadata.
- The frontend renders Markdown as escaped text, not HTML, to avoid XSS and sanitizer complexity.
- The ambiguous top-right global refresh icon was removed; automatic polling and the storage-folder refresh button cover the remaining refresh cases.
- The top-right controls now keep storage readout, usage calculation, addon download, and thumbnail blur in that order.
- The main job list now shows an always-available `ALL` filter plus source filters for providers currently present in job history.

- Frontend: document normalization, viewer loading, document strip labels, and scrollable escaped text panel in `app/templates/index.html` and `app/static/style.css`.

## Thumbnail Deferred Request Queue

Time: 02:15 KST
Commit: this commit
Status: verified

### Summary

- Card thumbnails now render with `data-thumbnail-src` first, then enter a viewport-triggered frontend queue.
- The browser runs at most 3 active `/api/media/thumbnail` requests and shares one loaded URL across duplicate job/mobile/library images.
- Slow or stuck thumbnail loads release their frontend queue slot after 60 seconds; server-side thumbnail ffmpeg work is still protected by the existing semaphore and 30-second subprocess timeout.
- First visits and existing filesystem cards still use lazy thumbnail generation, but the browser does not dispatch 100 uncached thumbnail requests at once.
- Generated card thumbnail JPEGs continue to live under `/config/media-cache/thumbnails`.

### Code And Docs

- Backend: no backend changes.
- Frontend/addon: deferred thumbnail queue, duplicate URL sharing, viewport registration, non-IntersectionObserver fallback, and request timeout in `app/templates/index.html`.
- Tests: template assertions for the queue, `data-thumbnail-src` rendering, concurrency limit, viewport observer, timeout, and render-time setup in `tests/test_review_fixes.py`.
- Docs: updated `docs/feature-code-map.md`, `docs/architecture.md`, `docs/operations.md`, and this note.
