## Civitai Metadata, ASMR Resilience, And Library Recovery

Time: 19:48 KST
Commits: `930cd33`, `ed65f9a`, `586f591`, `078f7ae`
Status: verified

### Summary

- Civitai model downloads now save example image generation metadata next to the model.
- The new `_civitai_generation_metadata.json` sidecar stores normalized prompt, negative prompt, seed/steps/sampler/CFG-style fields, raw generation metadata, and image page links for up to the first 100 model-version gallery images.
- Model-version `images` from the model metadata are kept ahead of images API gallery results, so the page's representative example image becomes the first `civitai_example_<imageId>.*` thumbnail when available.
- Model page body, version notes, trigger words, tags, file details, creator, model type, and base model are normalized into `model_details` and shown in the viewer before the generation prompt sections.
- The Civitai model detail panel now also surfaces status, published date, base model type, model/version stats, file hashes, required flags, and scan results from the normalized sidecar.
- Civitai model page SSR metadata is merged best-effort so page-visible filenames are preserved when the public v1 API returns older names.
- Civitai tensor metadata summaries now add primary-file tensor count and VRAM min/rec estimates to the sidecars and viewer file badges.
- Civitai model downloads now save required version components, such as VAE and Text Encoder files marked with `metadata.isRequired=true`, alongside the primary model file unless the user explicitly selected a specific file. Primary/required component results are recorded in `component_downloads`.
- Generation metadata and preview image collection are best-effort. If the Civitai images API or preview image download fails, the model file download continues.
- Existing Civitai model cards now expose a right-click `갱신` action. It queues a refresh job for the same folder, keeps existing model/component files in place, and backfills or updates the Civitai sidecars and representative preview image.
- Civitai model media viewer now shows `Downloaded components` with a `Check components` action that checks local primary/VAE/Text Encoder files in the selected archive folder.
- The folder tree now refreshes when a job transitions to `done` with a target path, so newly-created download folders such as `stable-diffusion/loras/...` appear without a full page reload.
- Folder-tree construction now creates each level broadly and caps each folder's direct children so a large `hitomi` branch cannot hide later top-level route roots such as `huggingface` and `stable-diffusion`.
- Clearing job history now resets the stale DB-backed library index so existing Civitai model folders can be restored from sidecars after their job rows are deleted.
- Selecting a folder in the library view now calls `/api/library?mode=live&path=...`, so a stale global index does not hide child model cards or their `civitai_example_*` thumbnails.
- The storage folder header now has a manual refresh button for NAS/local filesystem changes, the tree initially expands only `/data`, and file/folder rename/move/delete actions update the tree/library in place instead of reloading the whole page.
- The default job table now has an `이동` column between log and controls, letting rows with a saved target path jump directly to that library folder.
- The default job table now loads 50 jobs per numbered page. `/api/jobs?limit=50&page=N` returns a wrapper with `jobs`, `page`, `total_count`, and `total_pages`, while the legacy `/api/jobs` array response remains available.
- Shared file-name sanitizing for sources such as Civitai, HuggingFace, and ASMR.one now preserves Japanese, Chinese, and other Unicode language characters instead of collapsing paths such as `イラスト` into `folder`.
- ASMR.one work downloads now keep successful files when one downloadable track/image/attachment fails. The failed entry is recorded in `_asmrone_manifest.json`; the job only fails if no downloadable file can be saved.
- ASMR.one removes empty child directories left behind by failed media requests, so a blocked image folder does not remain as an empty placeholder.
- ASMR.one work cover metadata is saved as `cover.jpg` when available, then reused for audio archive cards, media-strip thumbnails, and the audio player cover in the media viewer.
- ASMR.one image attachments that resolve to Cloudflare HTML/error-placeholder responses are discarded and recorded as failed entries instead of being kept as broken local images.
