## Transfer Settings UX Split

Time: 2026-07-07 KST
Commit: `pending`
Status: verified

### Summary

- Split the transfer settings pane into separate areas for connected-folder target creation, `/data` root clone jobs, and registered target management.
- Moved Receiver/rclone target fields behind an advanced disclosure so the normal Portainer `/data_remote` flow is the first visible path.
- Changed the connected-folder defaults to allow common archive roots and leave include patterns empty, so images and mixed folders are not silently filtered out by model-only defaults.

### Deploy Impact

- No schema or environment changes. Existing transfer targets remain compatible; this only changes the settings-pane layout and local mount defaults for newly created targets.
